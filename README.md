# Dev Toolbox

A Chrome extension (Manifest V3) with context-menu shortcuts for everyday dev work.

## Features

### Switch domain
Swap the current tab's domain while keeping the path, query and hash —
e.g. `test.com/dashboard/2` → `test-qa.com/dashboard/2`.

- Right-click a page → **Switch domain** → open in the same tab or a new tab.
- Or click the pinned toolbar icon for the same actions.
- Rules are configurable in the options page (subdomains and ports supported).

## Install
1. Open `chrome://extensions` and enable **Developer mode**.
2. Click **Load unpacked** and select this folder.
3. Pin **Dev Toolbox** from the extensions (puzzle) menu.
